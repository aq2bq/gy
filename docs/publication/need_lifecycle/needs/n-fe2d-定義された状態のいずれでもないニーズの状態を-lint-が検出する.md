## 出所

N-14 と同じ報告（Q-19）から派生する。`status: done` のように定義された状態のいずれでもない値を書いても、`base_state` が一致せず need は完了と見なされないまま、lint は何も言わない。記録したつもりが効いていない状態を検出できない。

L10 は要求の状態を同じ意味で検査している。ニーズの状態にも同じ意味を適用するのか、別の規則にするのかは実装時に設計し、判断が割れるなら PO に投げること。
