## gy にとっての意味

変更系コマンドの JSON 出力は CLI と MCP の契約であり、利用側スクリプトが `node.body` を読んでいれば非互換になる。一方、`--body-file` で渡した本文をそのまま返すことは、エージェントが直前に生成した長文を再読することに直結する。

## トレードオフ

| 案 | 互換性 | 削減効果 | 一貫性 |
|---|---|---|---|
| 1. 全変更系が id と更新属性名だけを返す | 非互換（次の 0.y） | 最大 | 変更系と参照系の役割が分かれる |
| 2. `--body-file` 指定時だけ本文を省く | 互換 | 本文再読は消える | 同じコマンドで形が変わる |
| 3. 現行維持 | 互換 | なし | 変わらない |

## 推奨

案 1。変更系は「何が変わったか」、参照系（show / find）は「何であるか」を返すという責務分離で、他のコマンド（criterion satisfy、decide、link）にも同じ意味が通る。次に非互換変更をまとめる版で他の非互換項目と同時に出す。
