### 満たす条件

1. **全文が読める場所**: 一覧の Title 列（N-22 で達成）と詳細の見出し。ここは変えない。
2. **個別描画のラベル**: ID の下にタイトルを折り返して出す。折り返しは最大 3 行、1 行の幅はノード間隔に合わせて決め（レイアウトの最小間隔をラベル幅に合わせて広げてよい）、3 行に収まらないときだけ末尾を省略する。省略時も先頭全角 20 文字以上は残す。ラベル同士が重なるときは、片方を消すのではなく配置を広げる（力学配置の反発距離をラベル寸法に含める）。
3. **クラスタのラベル**: scope / type · 件数を読める大きさで出す（フィット直後の文字高 11px 以上、AC-3 と同じ基準）。
4. **フィット**: 表示対象が変わったときの自動フィットは、ラベルの広がりを含めた矩形で計算する（AC-3 の維持）。
5. **数値は測って確定する**: 実台帳（gy 自身、134 ノード）と E2E の reading fixture で、個別描画の全ノードについて「タイトル全文が出た件数 / 省略された件数 / 省略時の残り文字数の最小値」を測り、AC-29 の evidence に書く。省略時の最小残り文字数が全角 20 未満なら D-43 の数値を question にして私へ送る。
