## 対象と事実

N-25 の完了条件にある「CI の check ジョブの結果」の実行場所に限る問い。実装は f47b0c8 までコミット済み。AC-30.verification に測定結果を保存した。

CI の html-e2e ジョブに Bun 1.4.0 と bun run check を追加し、その同一コマンドをローカルで実行した。クリーンなコミットでは exit 0、生成元CSSへの不一致注入では exit 1、復元後は exit 0。act --list は両ジョブを認識したが、この環境に Docker 接続がなくジョブは実行していない。GitHub Actions も push 未承認のため未実行である。D-26 は CI を Linux とするが、この受け入れ時点でローカルの結果を代用できるかは定めていない。

## 選択肢と推奨

案Aを推奨する。CIへ追加した同一コマンドのローカル成功と不一致検出を根拠にAC-30を満たし、GitHub上のLinux実行はpush承認後に確認する。未実行の範囲を明示したまま後続の画面作業を進められるが、Linuxでの再現一致は受け入れ後の確認になる。

案BはAC-30を未達のまま保持し、push承認後のGitHub CI成功を待って満たす。要求の「CIの結果」を実行済みのLinuxジョブで裏付けられるが、後続を進める受け入れがpushの判断待ちになる。

デック先生はCIを実行済みとは記録せず、AC-30をまだsatisfyしていない。どちらの案でもpushと公開はマスター指示待ちを維持する。
