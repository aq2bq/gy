## 5 業務

1. **指名到達**: ID から 1 手でそのノードを開く。AI の発話や他の文書の ID を貼って開ける。
2. **絞り込んで一覧を読む**: 種別・スコープ・状態で並べて眺める。
3. **読む**: ノードの本文・属性・関係を台帳のまま読む。
4. **辿る**: 今いる場所を保ったまま周辺のノードを見て、戻れる。
5. **状況把握**: 未解決、詰まり、進捗を俯瞰する（Blockers / Progress が担っている部分）。

## 原則との関係

D-38〜D-43 の 6 原則は、この 5 業務から導いた設計原則である。以後の HTML projection への要求は、どの業務に属するかと、どの原則に照らして成立するかで裁く。原則に反する要求は question にする。
