# d-0621 (D-25) HTMLの自己完結性は読込時と描画操作時に外部取得を行わないことで検証する

## 関係
- 無し

decision_scope: 単一HTMLの読込とページ内操作に適用する。データ中のURLと利用者が明示的に辿るhttp/httpsリンクは許す。Rustは直接記述された外部参照のトークンを検査する粗い網とし、構文解析や実行時通信の保証とはしない。Chromium E2EはURL入り合成台帳を含めHTTP(S)要求の試行0件を検査する。CDN、Webフォント、外部画像、描画時通信を許可する変更ではない。
scope: html_projection
created: 2026-09-13
## Context

詳細の pr_url リンク生成コード中の href= を旧Rust検査が外部参照と誤判定した。裸の https:// の禁止も、正当なURL属性を持つ実台帳とは両立しなかった。クロコさんの検収で判明し、発注書§3が禁止している対象はページの外部取得であることを確認した。

## Decision

静的トークン検査を src/href の引用符直後の http、@import、url(http、<link に絞り、URL属性を持つ回帰例を同時に追加する。利用者が辿るリンクは外部取得の依存に数えない。静的検査は粗い網に留まり、実行時の契約は各E2EでHTTP(S)要求の試行を観測する。

## Consequences

リンクをクリックして外部へ遷移する操作はオフライン検証の対象外。ページの読込・詳細表示・グラフ操作はネットワークに依存しない。コードや埋込データの部分文字列だけで自己完結性を保証したと報告しない。
