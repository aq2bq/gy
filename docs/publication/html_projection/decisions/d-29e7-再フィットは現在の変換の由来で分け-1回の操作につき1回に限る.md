## 成立範囲

変換がフィット由来か利用者の操作由来かを保持する。表示対象が変わったときは由来を問わず再フィットする。描画領域の大きさだけが変わったとき（詳細パネルの開閉を含む）は、フィット由来なら再フィットし、操作由来なら倍率と画面中心のグラフ座標を保つ。焦点と詳細の状態を先に更新し、1回の draw で双方を評価してフィットを1回にまとめる。無条件の再フィットは利用者が拡大して見ていた位置を失わせ、再フィットしないと狭まった領域からノードが出る
