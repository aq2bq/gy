## 関係

- targets ac-1b8a (AC-15) 母数の概念が無いゲートの合格を、数値を作らずに記録でき、母数のあるゲートでは母数の欠落が検出される

## 本文

## 出所

kokopelli-recurring-v2 の進行管理担当から 2026-09-13 に報告。RSpec は 791 examples という母数を持つが、Sorbet と migration には母数の概念がない。報告者は sorbet/config の対象ファイルを数えて 115 と埋め、数えたのが自分であることを記録に残した。

## 再現

example の `quality_gates` schema をそのまま使い、母数のないゲートを passed で記録した。

```
error: quality_gates.results[0].result.denominator is required
exit=2
```

`passed` variant が `denominator` を必須にしている。他の variant（failed / not-executed / existing-violation / not-applicable）はどれも「合格した」を意味しないため、正直に記録する手段がない。

## 判定

採用する。ただし core の変更ではない。variant の仕組みは既にこの区別を表現できる。欠けているのは example の profile の設計で、これは gy が配布しているものだから gy が直す。

母数のあるゲートで母数を書かせる意図は維持する。合格の variant を、母数のある場合とない場合に分ける方向で設計し、workflows.md にその使い分けを書く。

## 閉じ方

- 事実で閉じた（ゲートは D-68 で第一級概念から外し、gy 0.5 に無い（d-736e））
